# actividades-python-ramas

## Descripción

Este proyecto contiene un programa desarrollado en Python que permite calcular el valor total de una factura incluyendo el IVA.

## Objetivo

Practicar conceptos básicos de programación en Python, como:

- Variables
- Entrada de datos con `input()`
- Operaciones matemáticas
- Cálculo de porcentajes
- Salida de información con `print()`

## Funcionamiento

El programa realiza los siguientes pasos:

1. Solicita el valor de la compra.
2. Calcula el IVA correspondiente.
3. Suma el IVA al valor de la compra.
4. Muestra el total de la factura.

## Ejemplo

Si el valor de la compra es de $100.000 y el IVA es del 19%:

- Subtotal: $100.000
- IVA: $19.000
- Total: $119.000

## Ejecución

Para ejecutar el programa se necesita tener instalado Python 3.

```bash
python factura.py
